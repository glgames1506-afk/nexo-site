# Operacao de Entrega

## Ferramentas

Use uma ferramenta de musica com permissao comercial no plano pago. Antes de vender em escala, confira os termos atualizados da plataforma escolhida.

Opcoes comuns:

- Suno em plano pago
- Udio em plano pago, se downloads e termos comerciais estiverem disponiveis na data de uso
- Outra ferramenta com licenca clara para uso comercial

## Fluxo manual do MVP

1. Cliente chama no WhatsApp.
2. Voce envia o roteiro de briefing.
3. Cliente paga.
4. Voce transforma o briefing em prompt.
5. Gera 2 opcoes de musica.
6. Escolhe a melhor.
7. Revisa a letra.
8. Entrega MP3, letra e capa simples.
9. Pede depoimento.

## Prompt base para gerar letra

```text
Crie uma letra de musica romantica em portugues do Brasil.

Ocasião: [OCASIAO]
Estilo: [ESTILO]
Voz: [MASCULINA/FEMININA]
Nomes: [NOMES]
Historia: [HISTORIA]
Detalhes obrigatorios: [DETALHES]

Regras:
- Nao cite artistas reais.
- Nao copie musicas existentes.
- Use linguagem simples, emocional e cantavel.
- Inclua detalhes especificos da historia.
- Crie verso, pre-refrao, refrao, verso 2 e refrao final.
- O refrao deve ser facil de lembrar.
```

## Prompt base para gerar a musica

```text
Musica romantica em portugues do Brasil, [ESTILO], [VOZ], clima emocionante e presenteavel, letra original sobre a historia de um casal, arranjo moderno, melodia memoravel, refrão marcante.
```

## Checklist antes de entregar

- A letra nao tem nome errado.
- A pronuncia dos nomes esta aceitavel.
- Nao parece imitacao de artista famoso.
- O audio nao esta cortado no comeco ou no fim.
- O arquivo foi renomeado com nome simples.
- A mensagem de entrega reforca que ha 1 ajuste de letra incluso.
