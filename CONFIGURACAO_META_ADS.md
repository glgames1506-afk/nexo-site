# Configuracao Meta Ads

## Objetivo

Validar a oferta com orcamento pequeno levando para WhatsApp ou landing page.

## Campanha inicial

| Nivel | Configuracao |
| --- | --- |
| Campanha | `MUSICA IA | Romance | WhatsApp | Teste 01` |
| Objetivo | Leads ou engajamento com destino WhatsApp |
| Orcamento | R$20/dia por 7 dias |
| Posicionamentos | Advantage+ |
| Local | Brasil ou sua cidade/estado, dependendo da capacidade de atendimento |
| Idade | 20 a 48 anos |
| Genero | Todos |
| Segmentacao | Relacionamento serio, namoro, casamento, presentes, Dia dos Namorados, aniversario, noivado |

Se o publico ficar pequeno, use publico amplo com Advantage+ ligado. O criativo emocional tende a filtrar melhor do que segmentacao muito travada.

## Mensagem inicial do anuncio

```text
Oi, vi o anuncio da musica personalizada e quero criar uma para uma pessoa especial.
```

## Metricas para decidir

| Metrica | Sinal bom inicial |
| --- | --- |
| Custo por conversa | Ate R$8 no teste |
| Conversas com historia enviada | 30% ou mais |
| Conversas que viram pagamento | 10% ou mais |
| Tempo de entrega | Menos de 40 minutos de trabalho manual |
| Reembolso/retrabalho | Baixo ou controlavel com 1 revisao |
| Upgrade para completo | 20% ou mais dos compradores da entrada |

## O que nao prometer

- Nao prometa imitar cantor famoso.
- Nao diga que a musica tera registro autoral garantido.
- Nao use depoimentos inventados como se fossem reais.
- Nao prometa entrega em minutos ate ter processo testado.
